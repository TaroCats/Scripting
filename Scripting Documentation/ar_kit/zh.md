全局 `ARKit` API 在兼容设备上使用后置摄像头跟踪全身动作，使用前置摄像头跟踪人脸。启动会话前，可用 `ARKit.getCapabilities()` 查询全身跟踪能力，用 `ARKit.getFaceTrackingCapabilities()` 查询人脸跟踪能力。

- [ARKit 全身跟踪](scripting://doc?title=ARKit%20Body%20Tracking) 介绍会话控制、关节变换、跟踪质量及下蹲计数 Demo。

- [ARKit 人脸跟踪](scripting://doc?title=ARKit%20Face%20Tracking) 提供前摄实时人脸位姿、表情权重和原生人脸网格。

- [ARKit 世界跟踪](scripting://doc?title=ARKit%20World%20Tracking) 提供相机跟踪、平面检测、世界坐标射线和锚点。
