# 空间音频

将单声道声源连接到 `AVAudioEnvironmentNode`，再将环境节点接入主混音器。每个声源使用可用输入总线，通过 `setMixing()` 设置位置和渲染算法。读取 `getMixing().supported` 和环境节点的 applicableRenderingAlgorithms；可用算法随输出格式和设备路由变化。

`configure()` 控制听者位置/方向、距离衰减、混响、输出类型和音量。同一次更新选择向量方向或角度方向其中一种。位置单位是米。距离及算法影响空间效果，耳机和扬声器的听感可能不同；此 API 不会自行启用头部跟踪。

声源混音还暴露支持的遮挡、阻隔、混响混合及声源/头部模式。返回的 supported 列表说明节点支持哪些控制，不应假设所有普通节点都支持全部 3D 参数。

## 完整 index.tsx

示例本地生成两路低音量单声道测试音，置于听者左/右侧。按钮移动听者，位置和频率同时以文字显示，不能听到声音时也能理解控制。停止和关闭会释放图及缓冲区。请不要与其它使用共享设备音频会话的脚本同时运行。

点击文档的示例入口即可运行，完整代码见同级 [index.tsx](index.tsx)。
