# 受保护脚本与许可证 API

将脚本发布为加密副本，通过 Scripting HTTPS API 生成激活码，让接收者无需登录即可激活。

## 完整使用流程

1. 在 **更多 → 设置 → 开发者 → GitHub** 中通过 GitHub 登录，并启用 Scripting 开发者身份。
2. 在脚本菜单中选择 **发布加密脚本**，保留原可编辑项目，将生成的 `.scriptingenc` 文件分享给接收者。
3. 在 GitHub 页面打开 **许可证 API 令牌**，创建“许可证管理”令牌并立即保存。令牌内容仅展示一次；可通过“发送到自己的设备”将它交付到自己的 Mac 或其他可信目标。
4. 在自己的工具或服务器中配置令牌，调用 `GET /packages` 获取已发布脚本的 `packageID`。
5. 调用 `POST /packages/{packageID}/licenses/batch` 生成激活码，安全保存返回的激活码，再发给对应接收者。
6. 接收者导入加密文件、输入激活码，即可运行已激活版本，无需 GitHub 或 Scripting 开发者账号。

App 负责管理 API 令牌，激活码通过 API 生成。开发者无需自建激活服务器。

## 第一个请求

示例从环境变量或秘密管理工具读取令牌。请勿把令牌提交到源码仓库、写入日志或放入 URL。

```sh
SCRIPTING_API_BASE='https://protected-api.scripting.fun/v1/protected'
# 从私有配置提供 SCRIPTING_LICENSE_TOKEN。
curl --fail-with-body --silent --show-error \
  -H "Authorization: Bearer ${SCRIPTING_LICENSE_TOKEN}" \
  "${SCRIPTING_API_BASE}/packages"
```

完整请求和响应约定见“认证与 API 令牌”“已发布脚本包”“许可证与激活码”“设备激活记录”“错误处理与安全重试”。

## 支持的脚本行为

- 支持 JavaScript/TypeScript/TSX 项目、相邻的 JavaScript 和 JSON 模块，以及 Scripting API。包含所有现有项目入口：主 App、快捷指令、App Intents、蓝牙、小组件、控制组件、通知、Spotlight、助手工具、键盘、实时活动、闹钟实时活动、翻译 UI、Safari 和首页 UI。
- 不支持以 Python 项目发布，也不支持外部 npm 包、原生扩展或任意资源文件。
- 先在主 App 中激活导入的版本，其可用入口随后会出现在原有选择器中。系统权限、扩展设置及对应 API 的正常执行要求仍然适用。激活不会自动注册蓝牙后台任务或准备远程更新。
- 各入口共用一张模块表。小组件可以导入 `index.tsx`；共享依赖只打包一次，在每个 JavaScript 上下文中初始化一次。小组件与 App 等独立上下文各有自己的状态。
- `browser.tsx` 明确保留代码可见：导入后可选择“查看浏览器代码”，Safari 也可以检查注入的 JavaScript。原有 DOM、用户脚本元数据和依赖规则继续适用。其他原生入口在磁盘上保持加密，在内存中加载。
- 导入根据文件内容识别加密脚本，即使保护文件被改名为 `.zip` 或 `.scripting` 也会识别。普通脚本导入仍可使用。
- 已激活版本可离线运行。许可证覆盖同一脚本包的有效版本，包括后续版本；目前不提供按版本范围定价的授权。
- 导入新版本会保留原来可运行的加密副本。可通过“使用已有激活”获取导入版本的授权。
- 分享操作发送加密副本，此流程不会把原可编辑项目交给接收者。
- 加密导出文件最大为 32 MiB，最多 512 个模块，单模块最大为 4 MiB。编译产物超过这些范围时，项目可能无法发布。

请保留原始项目和使用密码加密的发布私钥备份。“发布私钥”页面支持备份、恢复和轮换，详见“发布私钥备份与轮换”。重命名项目前先导出备份，再在新名称下恢复，之后再发布。

蓝牙后台和远程实时活动的冻结包保留准备时的加密版本。更新已安装副本不会替换其渲染代码。删除该版本会移除本机执行密钥；需要时重新准备或注册要使用的剩余版本。远程渲染沿用原有的 16 MiB 包大小限制，包含固定的运行时。

## 需要了解的边界

API 令牌管理你名下的许可证，不用于解锁脚本或发布版本。接收者使用自己的安装绑定激活身份，无需你的 API 令牌。设备绑定依据安装的密码学身份，而非硬件 UUID；替换安装身份需要有可用设备名额。

禁用许可证或撤销设备绑定，会阻止后续在线授权请求，已经交付的离线授权仍然可用。撤销 API 令牌会阻止该令牌后续调用 API，不会撤销接收者的许可证。

接口不可用时可能返回 `404`。请检查服务地址和接口是否可用，不要将该响应理解为当前账号没有记录。
